# Screens and routes

| Route | Screen |
| --- | --- |
| `#/sign-in` | Sign in (email/phone + password, show password, forgot password mock) |
| `#/` | Dashboard (key figures, charts, health tasks, calving, sales today, activity) |

| `#/customers/:id` | Customer profile (sales history, statement, receive payment) |
| `#/expenses` | Expenses (add, filters, category chart, export) |
| `#/health` | Health (records, withdrawal control, reminders, vets) |
| `#/labour` | Labour (employees, attendance, tasks, leave, payroll) |
| `#/reports` | Reports centre (9 reports, presets, Excel/PDF export) |
| `#/notifications` | Notifications (on-screen list + SMS/email log) |
| `#/audit` | Audit log (filters, before/after view) |
| `#/settings` | Settings (farm, integrations, payroll rates, users/permissions, backups, demo) |
